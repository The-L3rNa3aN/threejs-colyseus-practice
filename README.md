# ThreeJS Colyseus Practice
### Practice project for learning Colyseus using NodeJS. Originally made for [Project Zwei](https://github.com/The-L3rNa3aN/ProjectZwei).<br>

(Contrary to the name, this does not have ThreeJS. Sorry.)

Consists of the traditional client-server structure. The client's a simple HTML file while the server can be compiled into an executable which runs on the system and has a tool for starting both the server and its respective tunnel. It makes use of Caxa for packaging after a lot of experimentation.

## The client. Just a simple HTML.
Open it in your preferred browser and run!

### To join your friend's server:
 - Ask your friend for the invite link (roomId@url) and paste it in the designated area before joining.

### To start a server of your own:
 - Run the [executable](https://github.com/The-L3rNa3aN/threejs-colyseus-practice/releases/tag/v0.0.0) or [build one on your own](https://github.com/The-L3rNa3aN/threejs-colyseus-practice/tree/main/my-server#readme).
 - Use the tunnel link and paste it in the designated area within "Create Room (Host)". This gives the room ID attached with the URL.
 - Share it with your friends.

### Notes
 - The server still runs as long as it is populated, even after the server host has left and assuming the server executable is still running.
